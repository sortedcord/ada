# Timeline and branch wireframes

```text
[Active: main v12] [Fork] [Rewind] [Compare]
main
├─ T01 input / narrative
├─ T02 input / narrative
└─ T03 [fork here] ├─ branch: alternate (T04...)
                   └─ branch: main (T04...)

selected turn: player-safe events | narrative versions | actions
[Regenerate narration] [Regenerate turn -> new branch] [Activate branch]
```

Fork, rewind, input edit, and full-turn regeneration explain that old history remains. Branch activation is confirmed and serialized with run state. Player mode shows only safe event/narrative differences; canonical/private comparison is a separate admin inspector.
